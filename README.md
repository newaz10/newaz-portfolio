# Personal Portfolio

This repository contains the source code for my personal portfolio website. The site serves as a central hub to showcase my professional software engineering experience, full-stack web applications, technical skill set, and competitive programming profiles.

The live application is deployed and accessible at: https://newaz-portfolio.vercel.app

---

## Tech Stack

* **Frontend Framework:** Next.js (TypeScript)
* **Styling:** Tailwind CSS
* **Deployment & Hosting:** Vercel

---

## Key Features

* **Responsive Design:** Fully optimized for fluid viewing across desktop, tablet, and mobile devices.
* **Project Showcase:** Detailed cards featuring core projects like GoTaste.uk, ChatApp, Crypto Tracker, and NextBlog with their respective tech stacks.
* **Experience & Skills Timeline:** A structured layout highlighting professional engineering milestones and technical competencies.
* **Performance Optimized:** Built leveraging Next.js server-side features and optimized asset delivery for fast load times.
